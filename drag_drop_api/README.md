# Drag and Drop API

## ¿Qué es?

La Drag and Drop API permite arrastrar y soltar elementos dentro de una página web. Esta función está integrada en los navegadores modernos y facilita la creación de aplicaciones web más dinámicas e interactivas.

## ¿Cómo funciona?

Para utilizar esta API es necesario definir tres acciones principales:

- **dragstart:** Se ejecuta cuando comienza a arrastrarse un elemento.
- **dragover:** Permite que un elemento pueda recibir otro elemento arrastrado.
- **drop:** Se ejecuta cuando el elemento es soltado en un lugar determinado.

## ¿Para qué se utiliza?

- Organizar archivos.
- Crear juegos interactivos.
- Diseñar editores de contenido.
- Mover imágenes o elementos dentro de una página.
